需要擁有 Minecraft Java 版的 Microsoft 帳號，並安裝官方 Minecraft Launcher。

三步開始遊戲

  1. 下載並解壓縮

    把 zip 解壓縮到任何資料夾，例如桌面。

  2. 執行 SavaruLauncher.exe

    按「開始遊戲」。啟動器會裝好 Java、Minecraft 1.21.1、Fabric 和所有模組，第一次要下載的檔案比較多。

  3. 在官方啟動器按「遊玩」

    官方 Minecraft Launcher 會自動打開並選好「Savaru IV - Kohtalon Mies」。登入 Microsoft 帳號後按「遊玩」。

進遊戲後到「多人遊戲」選 SAVARU，就能連線伺服器。

為什麼用啟動器

一鍵安裝

Java、Minecraft、Fabric、四百多個模組和設定檔，全部自動裝好。

更新最快

新版模組包一發布就能更新，不用等 CurseForge 審核。每次按「開始遊戲」都會檢查。

啟動器自動更新

有新版啟動器時，會自己下載、更新並重新開啟。

保留你的設定

模組包這一版沒改到的設定檔，會保留你自己的修改。

常見問題

Windows 跳出「Windows 已保護您的電腦」？

啟動器沒有付費的數位簽章，第一次執行時 Windows 可能會提醒。按「其他資訊」，再按「仍要執行」。

需要正版 Minecraft 嗎？

需要。請用擁有 Minecraft Java 版的 Microsoft 帳號，並先安裝官方 Minecraft Launcher。

遊戲檔案存在哪裡？

在 %APPDATA%\.savaru-iv。啟動器放在哪個資料夾都可以，換資料夾也不會遺失遊戲、帳號和設定。

可以用 CurseForge 安裝嗎？

可以，模組包也在 CurseForge 上。用 Savaru 啟動器的話，新版會比 CurseForge 更早拿到。

支援 Mac 或 Linux 嗎？

目前只有 Windows 64 位元版本。
